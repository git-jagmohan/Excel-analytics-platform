# 📊 Excel Analytics Platform

A full-stack web application that allows users to upload Excel files, analyze data dynamically, and generate interactive visualizations.

## 🚀 Features

- 📁 Upload Excel (.xlsx/.xls) files
- 📊 Dynamic data visualization
- 📈 Multiple chart types
- 🔍 Select custom X and Y axes
- 📉 Interactive analytics dashboard
- 📥 Export charts and reports
- 🗂️ Store and manage uploaded datasets

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- Chart.js
- Three.js

### Backend
- Node.js
- Express.js
- MongoDB
- Multer
- SheetJS (xlsx)
